# Resume Parsing with Google Gemini LLM
Transform messy resumes into structured data — automatically!  <br>
This project uses Google Gemini LLM to build an AI-powered Resume Parser that extracts key details (name, skills, education, experience) and even auto-fills forms with the parsed information.

## Features
✅ Upload Resumes: Supports PDF or DOCX files  <br>
✅ AI-Powered Parsing: Extracts candidate details using Google Gemini LLM  <br>
✅ Structured Output: Converts unstructured resumes into clean, usable data  <br>
✅ Form Auto-Fill: Automatically fills out application forms with extracted data  <br>
✅ User-Friendly Web App: Built with a simple and interactive interface  <br>

## How It Works
Upload a resume to the app  <br>
Process it with Gemini LLM for text extraction & parsing  <br>
Generate structured JSON/CSV data  <br>
Auto-Fill forms or save parsed data for later use  <br>

### Tech Stack

Google Gemini LLM  <br>
